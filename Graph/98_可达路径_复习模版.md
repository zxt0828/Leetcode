# 98. 可达路径（卡码网）

## 题目概述

给定一个有 n 个节点的**有向无环图**（DAG），节点编号 1 到 n，找出并返回所有从节点 1 到节点 n 的路径。

## 核心思路

**DFS + 回溯**：从节点 1 出发深度优先搜索，维护一个 `path` 记录当前路径，到达节点 n 时收集结果，回溯时撤销选择。

## 建图方式

### 邻接矩阵（本题使用）

```java
int[][] graph = new int[n + 1][n + 1];
graph[s][t] = 1; // 表示 s → t 有边
```

- 查询两点间是否有边：O(1)
- 遍历某节点的所有邻居：O(n)
- 空间：O(n²)
- 适合节点数较少、边较密的图

### 邻接表（稀疏图更优）

```java
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
graph.get(s).add(t); // 表示 s → t 有边
```

- 遍历某节点的所有邻居：O(该节点的出度)
- 空间：O(n + m)，m 为边数
- 适合节点多、边少的稀疏图

## 代码模版

```java
import java.util.*;

public class Main {
    public static List<List<Integer>> result = new ArrayList<>();
    public static List<Integer> path = new ArrayList<>();

    public static void dfs(int[][] graph, int cur, int n) {
        // 终止条件：到达目标节点
        if (cur == n) {
            result.add(new ArrayList<>(path)); // 注意要拷贝
            return;
        }

        // 遍历所有邻居
        for (int i = 1; i <= n; i++) {
            if (graph[cur][i] == 1) {
                path.add(i);              // 做选择
                dfs(graph, i, n);          // 递归
                path.remove(path.size() - 1); // 撤销选择（回溯）
            }
        }
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        int[][] graph = new int[n + 1][n + 1];
        for (int i = 0; i < m; i++) {
            int s = scanner.nextInt();
            int t = scanner.nextInt();
            graph[s][t] = 1;
        }

        path.add(1); // 起点加入路径
        dfs(graph, 1, n);

        if (result.isEmpty()) {
            System.out.println(-1);
        }
        for (List<Integer> pa : result) {
            for (int i = 0; i < pa.size() - 1; i++) {
                System.out.print(pa.get(i) + " ");
            }
            System.out.println(pa.get(pa.size() - 1)); // 最后一个不带空格
        }
    }
}
```

## DFS 回溯三步曲

1. **做选择**：`path.add(i)` — 把当前邻居加入路径
2. **递归**：`dfs(graph, i, n)` — 继续往下探索
3. **撤销选择**：`path.remove(path.size() - 1)` — 回来后把刚加的节点移除

## 易错点

| 易错点 | 说明 |
|--------|------|
| 路径拷贝 | 收集结果时必须 `new ArrayList<>(path)`，否则所有结果指向同一个引用 |
| 输出格式 | 最后一个节点后**不能有空格**，用 `print` 而非 `println` 输出中间节点 |
| 起点初始化 | 调用 DFS 前要先 `path.add(1)` 把起点放进去 |

## 复杂度

- **时间**：O(n! × n)，最坏情况路径数量为指数级，每条路径长度为 O(n)
- **空间**：O(n)，递归栈深度 + path 长度
